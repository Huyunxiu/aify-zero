# AI 操作的是用户看得见的浏览器

AI 通过服务端工具驱动桌面里的同一个浏览器视图，不另起一个后台浏览器。用户要求 AI 和
用户操作同一个页面；这要求服务端能向桌面发按会话、按视图限定的命令，并且 AI 动作发生时
页面必须可见。

## Considered Options

- 桌面内嵌 + CDP（采用）：AI 和用户看到同一个页面，登录态一致，延迟低；只支持桌面端。
- 服务端 Playwright + 画面投射：工具在同一进程里最简单，但交互延迟高，页面和用户实际
  使用的浏览器不是同一个。
- 第三方 MCP 浏览器：接入最快，但 AI 操作的不是面板里的页面。

## Consequences

- 服务端需要一条到桌面的命令通道，命令按会话和视图限定，不能操作任意目标。
- 动作前强制展开面板并切换到对应视图，用户始终看得见 AI 在做什么。
- 浏览器工具不逐次审批；依靠可见性、停止按钮、URL 限制和权限拒绝兜底。
- 页面内容是外部输入，工具输出必须标记为不可信，系统提示要求模型把页面文本当数据。
- 没有桌面连接时，浏览器工具返回可读错误，不静默消失。
