# 浏览器档案按项目共享并持久保留

浏览器视图需要一个登录态档案。同一项目内的所有浏览器视图共享一个持久档案，不同项目
互相隔离：同一个项目只登录一次，重启后仍然有效；不同项目的账号不会互相泄漏。

## Considered Options

- 全应用共用 + 持久：登录一次最省事，但任何会话的页面都能碰到你在其他会话登录过的站点，
  提示注入的影响面是全应用。
- 按项目共用 + 持久（采用）：登录体验接近，影响面限制在一个项目内。
- 按项目共用 + 进程内有效：最安全，但每次启动都要重新登录。

## Consequences

- 浏览器档案的键是项目 id；没有项目的会话回退到按会话隔离。
- 档案必须在创建视图时确定，运行中不能切换；要换范围只能重建视图。
- 用户需要一种清空浏览器档案的方式，这一项还没实现。
