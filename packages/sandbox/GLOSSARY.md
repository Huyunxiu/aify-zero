# Sandbox

会话的工具在哪跑：一个沙箱同时给出文件访问和命令执行两件事，工具只认这个面，
不认具体环境。

## Language

**沙箱 (Sandbox)**:
工具读写文件和运行命令的那个运行环境。它可能是本机，也可能是容器或远端机器；
工具看不出区别。
_Avoid_: 容器、执行器、后端、runtime

**沙箱适配器 (Sandbox Adapter)**:
把某一种环境映射成沙箱的那段代码。一个适配器对应一种环境。
_Avoid_: 提供方、供应商、驱动、插件

**本机适配器 (Host Adapter)**:
把 server 进程所在的那台机器映射成沙箱的适配器。它不提供隔离。
_Avoid_: 本地沙箱、默认沙箱

**原生隔离适配器 (Native Isolation Adapter)**:
在本机适配器外面套一层平台自带的约束，让命令和文件写入只能落到工作目录、会话目录、
临时目录和构建缓存的适配器。它仍然跑在同一台机器上。
_Avoid_: 容器、虚拟机、沙箱套沙箱

**容器 (Container)**:
Linux 里跑命令的那个隔离环境。一个容器可以是一个沙箱的实现，但沙箱不一定是容器。
_Avoid_: 沙箱、虚拟机

**挂载 (Mount)**:
把一个宿主目录接进容器、两侧路径不变的接线。写进挂载目录的改动两边都看得见。
_Avoid_: 映射、绑定、volume

**容器适配器 (Container Adapter)**:
让命令跑在容器里、文件动词按挂载集校验的适配器。与本机、原生隔离适配器不同，
它连读取也限制。
_Avoid_: Docker、隔离器

**沙箱 id (Sandbox Id)**:
会话用来认领自己那个沙箱的逻辑名字。一个会话一个。
_Avoid_: key、缓存键

**物理 id (Physical Id)**:
适配器在环境启动之后回报的、它那一侧的资源标识，用来回到同一个环境。
本机适配器没有这个值。
_Avoid_: handle、句柄、引用
