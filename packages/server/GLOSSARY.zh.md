# Server

> 中文副本。以 `GLOSSARY.md` 为准。

本机 API server：Bot、设置、项目、会话行和凭据，供应商与模型的配置也定义在这一层。
它监听端口、校验凭据、托管 web 产物，把 HTTP 与 WebSocket 两条通道交给浏览器和桌面。

## Language

**Bot**：
独立的持久配置实体，拥有专属身份、模型偏好、指令、能力面、Bot 主目录与 Bot 工作目录；每条会话归属于一个 Bot。
_Avoid_：Agent、智能体、助手、模板

**默认 Bot (Default Bot)**：
系统内置、不可删除的 Bot，承接未指定自定义 Bot 的会话与升级后的历史会话。
_Avoid_：系统 Bot、全局 Bot、兜底 Bot

**Bot 主目录 (Bot Home)**：
单个 Bot 在数据根下的私有目录（`~/.aify-zero/bots/<botId>/`），存放该 Bot 的文件型资源。
_Avoid_：系统目录、配置目录、操作系统目录

**Bot 工作目录 (Bot Workspace)**：
单个 Bot 跨会话使用的持久工作区，默认位于 Bot 主目录的 `workspace` 子目录；未挂项目时作为默认 `cwd`，挂项目时作为附加可读写根。
_Avoid_：项目目录、会话目录、临时目录

**资源 (Asset)**：
由一个 Bot 或一条会话拥有的文件，存放在该所有者目录的 `assets/` 下，经字节路由 `/api/asset`
对外提供。它的去留跟随所有者的删除规则，不会独自比所有者的文件树活得更久。
_Avoid_：静态资源、上传文件、附件、blob

**会话 (Session)**：
列表里的一行：标题、所属 Bot、可选挂载的项目、若干回合、一条分支和最后活动，也是
一次运行发生的地方。
_Avoid_：对话、线程、chat、thread

**删除会话 (Delete Session)**：
让一个会话不再出现在任何地方，但保留它的会话记录：列表和读接口都把它当成不存在，将来由回收站
处理。运行中的会话不能删。
_Avoid_：归档、移除、清空、回收站

**供应商 (Provider)**：
提供模型调用服务的一方，持有 API 地址、协议和密钥本身，或者一个提供密钥的环境变量名。
一个供应商下可以有多个模型。
_Avoid_：提供商、服务商、渠道

**供应商密钥 (Provider Key)**：
发起模型调用时带给供应商的凭据。它要么写在供应商行上（`apiKey`），要么只写一个环境变量
的名字（`apiKeyEnv`），而且那个名字必须落在 `AIFY_PROVIDER_KEY_` 命名空间里。两者互斥。
存下来的只是名字，所以读设置永远不会返回密钥本身。界面上这个字段叫「API 密钥」；这里
叫它供应商密钥，因为「API 密钥」也是访问令牌的叫法。
_Avoid_：token、访问令牌、私钥

**模型 (Model)**：
供应商提供的一个可调用模型。模型属于一个供应商，不持有接入信息。
_Avoid_：模型配置、AI 模型

**模型引用 (Model Ref)**：
供应商 id 加模型 id。会话、Bot 和设置用它唯一确定一个模型，不用拼接字符串。
_Avoid_：模型标识、完整模型名

**模型 id (Model Id)**：
供应商上游用来标识模型的字符串，可以自带 `/`。它和界面上的显示名不是一回事。
_Avoid_：上游模型名、wire 名

**API 地址 (API URL)**：
供应商服务的根地址。协议决定 SDK 在它后面追加的路径：`/chat/completions` 或
`/responses`。界面只填根地址，不填完整端点。
_Avoid_：基地址、接口根地址、服务地址

**协议 (Protocol)**：
供应商接受的请求格式。一个供应商只有一种协议；同一家要用两种就配两条。
_Avoid_：兼容类型、接口类型

**时区 (Time Zone)**：
用户所在地方的 IANA 名字，存在用户设置里；没配时取宿主。日程的日历规则在写入时把
它固化到自己身上，之后不再跟随设置。
_Avoid_：地区、本地时间、UTC 偏移

**访问令牌 (Access Token)**：
机器级凭据，证明请求来自这台机器的拥有者。桌面主进程、CLI 和脚本用它。
_Avoid_：API key、密钥、token

**登录态 (Sign-in Session)**：
浏览器证明自己身份的一段凭据，放在 HttpOnly cookie 里。它按主机名生效，页面
脚本读不到。
_Avoid_：会话、session（会和 agent 会话混淆）

**登录票据 (Sign-in Ticket)**：
用来换一条登录态的凭据，只出现在登录链接里。它绑定在签发它的那次进程运行上：
重启后失效，同一次运行里可以重复使用。
_Avoid_：临时令牌、验证码、magic link

**来源白名单 (Trusted Origin Set)**：
允许携带登录态的浏览器源。cookie 会被浏览器自动带上，所以判断请求来自哪个
页面只能看 `Origin`。
_Avoid_：CORS 名单、允许域名

**就绪消息 (Ready Message)**：
本机 API server 报告自己已经可以服务请求的信号，携带实际监听地址。桌面靠它
知道该把请求转发到哪里；独立启动时没有这条消息，只看终端打印的监听行。
_Avoid_：就绪行、ready line、握手行

**最后活动 (Last Activity)**：
会话的时间所指的那个时刻：它的回合开始或回合结束。改名和标记已读不算活动；
开机恢复、清理残留标记、压缩也不算。它不是「这一行最后一次被写入」的时刻。
_Avoid_：更新时间、最后修改时间、最近使用
