# UI

会话面板与其中的各个视图：文件、改动、终端、浏览器。它把会话能碰到的外部状态——
工作区文件、git 改动和网页——画成可点、可看的区域。

## Language

**改动视图 (Review View)**:
会话面板里的一个视图，右侧列出改动，左侧画出选中改动的内容差异。
_Avoid_: 变更页、diff 面板

**改动 (Change)**:
工作区里相对基线有差异的一个文件路径。一个路径算一处改动，与它被改了几次无关。
_Avoid_: 变更项、diff、补丁

**基线 (Baseline)**:
用来判断「改了什么」的参照。当前是仓库的 `HEAD`；仓库还没有第一个提交时，基线是空树。
_Avoid_: 目标版本、原始版本

**未跟踪文件 (Untracked File)**:
git 没有记录过的文件。它相对基线是一处完整的新增。
_Avoid_: 新文件、未纳入版本

**改动状态 (Change Status)**:
一处改动相对基线的性质：新增、修改、删除、重命名、未跟踪。
_Avoid_: 差异类型、变更种类

**纯重命名 (Pure Rename)**:
路径变了、内容没变的改动。改动视图对它的左侧把整份内容按新增显示。
_Avoid_: 空改动、只有路径变化

**浏览器视图 (Browser View)**:
会话面板里显示网页的视图，用户和 AI 操作同一个页面。一个浏览器视图占一个面板标签。
_Avoid_: 浏览器标签、网页页签

**页面快照 (Page Snapshot)**:
某一时刻页面的可操作结构，供 AI 阅读。
_Avoid_: 页面结构、DOM 树

**页面引用 (Page Reference)**:
页面快照里指向一个页面元素的标识，在下一次快照后失效。
_Avoid_: 元素 id、选择器

**浏览器档案 (Browser Profile)**:
同一项目内所有浏览器视图共享的登录态存储；不同项目互相隔离。
_Avoid_: 用户配置、cookie 库
